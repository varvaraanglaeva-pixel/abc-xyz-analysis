# ABC-XYZ анализ ассортимента в Power BI

**Задача:** сегментировать товарный ассортимент компании по двум осям — вклад в выручку (ABC) и стабильность спроса (XYZ). Это позволяет бизнесу понять, какие товары приносят деньги стабильно, а какие — случайные или убыточные позиции, на которых не стоит фокусировать закупки и маркетинг.

**Данные:** история продаж за ~2 года, разбитая по месяцам и товарным группам. Перед анализом данные прошли через Power Query: объединение запросов, очистка типов, фильтрация нерелевантных строк, добавление вычисляемых столбцов.

**Методология:**
- **ABC-классификация** — ранжирование товаров по доле в общей выручке. Класс A — топ-позиции, дающие основной доход; класс C — длинный хвост.
- **XYZ-классификация** — оценка стабильности спроса через коэффициент вариации (CV). Класс X — стабильный спрос, класс Z — хаотичный, практически непредсказуемый.


**Реализация в DAX:**
- Мера Выручка — базовая агрегация
- Ранг по выручке — для ABC-разбиения
- Средняя выручка в месяц и Стд. отклонение в месяц — база для расчёта CV
- CV (Коэфф. вариации) = стд. отклонение / среднее
- ABC Класс и Класс XYZ — итоговые категории

### Что показал анализ

**Матрица ABC-XYZ:**

| Сегмент | Выручка | Значение  |
|---------|---------|---------------|
| A Z | 13 765 138 | Лидеры по выручке, но с хаотичным спросом — требуют особого управления запасами |
| B Z | 3 008 290 | Средний вклад, нестабильный спрос |
| C Z | 753 263 | Низкий вклад, нестабильный спрос — кандидаты на вывод из ассортимента |
| A X | 168 470 | Стабильные лидеры — ядро ассортимента |
| C X | 11 943 | Стабильный, но малый спрос — нишевые позиции |
| B Y | 11 130 | Умеренный вклад, умеренная нестабильность |
| B X | 10 115 | Стабильный средний сегмент |
| C Y | 8 295 | Хвост с колебаниями |
| A Y | 6 786 | Высокий вклад, но спрос колеблется |

**Общая выручка:** 18 млн за период анализа.

**Ключевой инсайт:** почти 75% выручки
 сегмент A Z — это товары-лидеры, но с непредсказуемым спросом. Бизнес теряет деньги либо на излишках запасов, либо на упущенных продажах из-за stock-out.

### Что бы я предложила бизнесу
1. **Сегмент A Z** — внедрить систему прогнозирования спроса.
2. **Сегмент C Z и C Y** — рассмотреть вывод из ассортимента или перевод под заказ
3. **Сегмент A X** — это «дойные коровы», держать максимальный уровень сервиса и не трогать без необходимости.
4. Настроить автоматический пересчёт классификации раз в квартал — ассортимент живой, сегменты мигрируют.
